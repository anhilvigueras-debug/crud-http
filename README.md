# CRUD de Productos con Sesión en Laravel 12 y Bootstrap 5

Proyecto desarrollado para la materia de Aplicaciones Web. Implementa un CRUD completo almacenado en sesión con filtrado y diseño responsivo.

## Requisitos y Tecnologías

- PHP >= 8.2
- Laravel 12
- Bootstrap 5 (a través de `laravel/ui`)
- Vite

## Características e Implementación

- **GET**: Listado de productos con filtros por nombre y categoría.
- **POST**: Creación de nuevos registros con validaciones visibles.
- **PUT**: Edición de productos existentes.
- **DELETE**: Eliminación mediante modal de confirmación en Bootstrap.
- **Mensajes Flash**: Alertas dinámicas al realizar operaciones exitosas.
